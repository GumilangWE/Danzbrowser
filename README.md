# 🌐 Danz Browser

A lightweight Linux browser built with **GJS + GTK3 + WebKitGTK 4.1**.

Designed to be simple, fast, and portable with AppImage support.

## ✨ Features

- 🚀 Lightweight WebKitGTK engine
- 🗂️ Multi-tab browsing
- 🔒 Persistent browser profile
- 🍪 Cookie storage
- 🌙 Dark theme support
- 📦 Portable AppImage
- 🐧 Linux friendly
